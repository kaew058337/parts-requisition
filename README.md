# Parts Requisition Turbo Skill

A performance-engineering skill for AI coding agents working on the Parts Requisition app.

## Install
Copy the `parts-requisition-turbo` folder into the agent's supported skills directory. For agents that recognize repository-local skills, this may be `.github/skills/parts-requisition-turbo/` or another configured skills path; check the agent's documentation for the exact path.

## Use
Ask your coding agent:
- “Use Parts Requisition Turbo to profile the stock calculation and suggest the safest performance improvement.”
- “Apply the smallest optimization to this slow lookup, then validate output parity.”
- “Benchmark this function before and after; report actual measurements only.”

## Safety
This skill does not authorize production deployment, data migration, changing business rules, or weakening stock validation. Review changes and test on a copy before deployment.

See `SKILL.md` for the complete instructions.

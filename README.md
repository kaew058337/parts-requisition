# ระบบเบิก-จ่าย-ส่งคืนพัสดุ (Google Apps Script + Google Sheets)

Web app มือถือสำหรับเบิก / รับ / จ่าย / ส่งคืน / ยืม / ตรวจนับ / FLY AWAY KIT
ใช้ Google Sheets เป็นฐานข้อมูล

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | Backend (Apps Script) |
| `Index.html` | หน้าเว็บทั้งหมด |
| `appsscript.json` | ตั้งค่า manifest |

## ติดตั้ง / อัปเดต (ใช้ Google Sheet เดิมได้เลย ไม่ต้องสร้างใหม่)
1. เปิด Google Sheet เดิมที่มีข้อมูลอยู่ → **ส่วนขยาย → Apps Script**
2. วางโค้ด `Code.gs` และ `Index.html` ทับของเดิม (`appsscript.json` ใช้ตัวเดิมได้)
3. บันทึก แล้วรีเฟรชชีท จะมีเมนูของระบบขึ้นมา ชีทที่ยังไม่มี (เช่น ชุดพัสดุ) สร้างได้จากเมนู
4. **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ไอคอนดินสอ) → เวอร์ชัน: เวอร์ชันใหม่** URL `/exec` เดิมจะไม่เปลี่ยน

> ถ้าตั้งระบบครั้งแรกกับชีทใหม่เท่านั้น ให้รันฟังก์ชัน `setup` หนึ่งครั้ง

## เชื่อม LINE LIFF
1. LINE Developers → Channel (LINE Login) → แท็บ **LIFF** → Add
2. **Endpoint URL** = URL `/exec` ของเว็บแอป, Size = Full, Scope = `profile`
3. คัดลอก **LIFF ID** ไปใส่ใน `Index.html` ที่ตัวแปร `LIFF_ID`
4. Deploy ใหม่ (เวอร์ชันใหม่) แล้วเปิดลิงก์ `https://liff.line.me/<LIFF ID>` ใน LINE
5. ชื่อ LINE จะถูกตั้งเป็นชื่อผู้ใช้อัตโนมัติ (ถ้ายังไม่เคยตั้งชื่อ)

> หมายเหตุ: ทุกครั้งที่แก้โค้ดต้อง Deploy เวอร์ชันใหม่ จึงจะมีผลที่ URL เดิม

## อ่านตาราง Schedule งาน TCI (Excel ของหัวหน้า)
1. ชีทนี้: ไฟล์ > นำเข้า > อัปโหลด > เลือก "แทรกชีทใหม่" แล้วเปิดแท็บของเดือนนั้น
2. เมนู ระบบเบิก-จ่าย > อ่านตาราง Schedule TCI — ระบบเติมรายการลงชีท "นำเข้าใบเบิก" (มี S/N = LRU(TCI), ไม่มี = SP(TCI); ข้ามรายการที่ไม่มี P/N)
3. กรอกผู้เบิก ตรวจรายการ แล้วกด นำเข้าใบเบิก

## สำรองข้อมูลอัตโนมัติ
